## Overview

The `mixr` package fits linear mixed-effects models, centered around the
`nlme` package. It is centered around fitting many models of identical
form, from a list of features as the response variable.

------------------------------------------------------------------------

## Installation

``` r
# current dev version
remotes::install_github("stufield/mixr")

# or a specific version
remotes::install_github("stufield/mixr@v0.0.1")
```

## Usage

To load `mixr` simply make a call to `library()` as usual:

``` r
library(mixr)
```
